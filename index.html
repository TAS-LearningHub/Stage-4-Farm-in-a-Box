How the course works

Learn, check, apply and keep evidence

The same calm learning rhythm will repeat through all ten modules.

1. Learn

Use three named theory sections, purposeful visuals and a watch-and-notice pathway.

2. Check

Complete a closed formative package immediately after each section.

3. Apply

Use the learning in investigations, design decisions and production records.

4. Review and save

See what remains, keep evidence on this device, then print or export a backup.

Agriculture leads the learning. Food-specific nutrition and preparation sit outside this unit; the design challenge is a portable, water-aware crop-production system.
